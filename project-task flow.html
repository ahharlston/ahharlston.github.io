🚀 TaskFlow REST API

A backend service built with Java and Spring Boot to demonstrate RESTful API design and database persistence.

Technical Summary

  • Language: Java 21
  • Framework: Spring Boot 3
  • Database: H2 (In-memory)
  • Architecture: MVC (Model-View-Controller)

The Architecture

This project uses a layered architecture to separate concerns. By using Spring Data JPA, I was able to map Java objects directly to database tables, allowing for "Zero-SQL" data management.
